12. Un temps pour soi ↑ sommaire

Ce chapitre décrit le journal MeTimeLog : ses champs, les gestes qui l'écrivent (plafond quotidien, arrondi des heures, fusion d'une modification) et les calculs qui en dérivent (durée d'un jour, score quotidien, totaux de période, comptages, moyennes de l'accueil, série de tendance). Toutes les durées sont des minutes entières, toutes les dates des chaînes locales YYYY-MM-DD, toutes les heures des chaînes HH:MM.

Un seul objet du domaine est stocké : MeTimeLog, rangé dans appData.meTimeLogs.

Plafond quotidien (sport et temps pour soi)

L'ajout passe par addLogWithinDailyCap, plafond 15, identifiant metime-<Date.now()>. Le décompte porte sur les lignes réellement présentes ce jour-là.

addLogWithinDailyCap(logs, log, cap=15, newId, onCapReached) :
  duJour = logs.filter(item => item.date === log.date)
  si duJour.length < 15
     -> logs + [ snapLogTime({ ...log, id: newId }) ]
  sinon
     onCapReached()                      // « Limite atteinte pour aujourd'hui : cette saisie remplace la dernière. »
     index = dernier indice de logs dont date === log.date
     logs[index] = snapLogTime({ ...logs[index], ...log })
     -> logs

« La dernière du jour » est la dernière dans l'ordre du tableau, c'est-à-dire la dernière saisie, pas la plus tardive dans la journée. L'écrasement fusionne : la ligne garde son id, et un champ absent de la nouvelle saisie serait conservé.

Minutes rondes

Toute heure écrite est ramenée à la minute ronde inférieure. L'ensemble des minutes rondes est irrégulier, la règle s'applique donc au moment d'écrire dans le modèle, pas dans le champ.

ROUNDED_MINUTES = [0, 10, 15, 20, 30, 40, 45, 50]

snapToRoundedMinutes(time) :
  si time ne vaut pas /^(\d{2}):(\d{2})$/  -> time inchangé
  si minutes > 59                          -> time inchangé
  rounded = plus grande valeur de ROUNDED_MINUTES ≤ minutes  (sinon 0)
  -> `HH:${pad2(rounded)}`

snapLogTime(log) = typeof log.time === 'string' ? { ...log, time: snapToRoundedMinutes(log.time) } : log

snapLogTime est appliqué par addLogWithinDailyCap (ajout et écrasement) et par applyLogUpdate (modification) : les deux portes d'écriture. L'heure pré-remplie du formulaire vient de getRoundedLocalTimeStr(), qui est le même arrondi appliqué à l'heure locale courante. L'arrondi est toujours vers le bas, pour ne jamais produire une heure future ni franchir minuit. → fonctionnelle

Bornes numériques du sport et du temps pour soi

Une seule règle sert la durée des séances et celle des moments.

RULE_DURATION = { min: 1, max: 480, step: 5, unit: 'min',
                  message: 'Une durée entre 1 et 480 minutes est attendue.' }

sanitizeNumber(raw, rule) :
  decimals = rule.decimals ?? 0                       // 0 pour la durée
  cleaned  = cleanNumericInput(raw, decimals)         // virgule -> point, lettres et signe - retirés,
                                                      // un seul point, décimales tronquées
  si cleaned est '' ou '.'      -> rule.allowEmpty ? '' : null   // allowEmpty absent -> null
  si !Number.isFinite(valeur)   -> null
  si valeur < 1                 -> null
  si valeur > 480               -> null
  -> cleaned (sans point final orphelin)

isAcceptable(raw, rule) = sanitizeNumber(raw, rule) !== null
boundsMessage(rule)     = rule.message

Bornes incluses : 1 et 480 sont acceptés. decimals valant 0, « 45.7 » est tronqué en « 45 » à la frappe, pas refusé. step: 5 ne sert qu'aux flèches haut/bas du clavier (stepNumber), qui bornent la valeur au lieu de la refuser ; il n'impose pas un multiple de 5 à la saisie.

Score quotidien du temps pour soi

Un point par jour parcouru, score de 0 à 10 : les minutes du jour rapportées à une heure, plafonnées.

FULL_SCORE_MINUTES = 60

bornes de la fenêtre (computeRangeBounds) :
  dayStartMs = today.setHours(0,0,0,0) ; dayEndMs = dayStartMs + 86 400 000 − 1
  '7days'|'14days'|'30days'|'90days' -> startMs = dayStartMs − (n − 1) jours ; endMs = dayEndMs
  'all'    -> startMs = min( new Date(`${log.date}T12:00:00`) ) ; dayStartMs − 6 j si journal vide
  'custom' -> startMs = `${customStart}T00:00:00` ou dayStartMs − 6 j si vide
              endMs   = `${customEnd}T23:59:59`   ou dayEndMs      si vide

échantillonnage :
  diffDays  = Math.round((endMs − startMs) / 86 400 000)
  maxPoints = diffDays > 60 ? 60 : Math.max(diffDays + 1, 1)
  step      = Math.max(1, Math.floor((diffDays + 1) / maxPoints))

pour t = startMs ; t ≤ endMs ; t += 86 400 000 × step :
  dateStr      = getLocalDateStr(t)
  dailyMinutes = Σ duration des logs dont log.date === dateStr
  score        = Math.min(dailyMinutes / 60 × 10, 10)
  point = { dateFormatted: 'JJ/MM', timestamp: t, 'Score Temps pour soi': Math.round(score × 10) / 10 }

Le pas vaut 1 tant que diffDays ≤ 118, 2 à partir de 119 jours de fenêtre, 3 à partir de 179. Les jours sautés n'ont pas de point : ils ne sont ni tracés ni comptés dans le graphe, et leurs minutes n'apparaissent nulle part sur la courbe. L'axe des ordonnées est figé sur [0, 10].
