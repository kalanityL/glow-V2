Semis reproductible (creerRng)

creerRng(graine) {  // mulberry32
  let a = graine >>> 0
  return () => {
    a += 0x6d2b79f5
    let t = a
    t = Math.imul(t ^ (t >>> 15), t | 1)
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61)
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296
  }
}

Même graine, même suite, donc même scène : positions, délais et teintes des particules sont reproductibles et testables. « Rejouer l'animation » change la graine, ce qui resème la scène.

Sens d'une période (periodShift)

si series.length < 2 → null
moitie = Math.floor(series.length / 2)
avant  = Σ (v ?? 0) sur series[0 … moitie−1]
apres  = Σ (v ?? 0) sur series[moitie … fin]

si avant ≤ 0 || apres ≤ 0 :
   si avant ≤ 0 && apres ≤ 0 → 'stable'
   return apres > avant ? 'hausse' : 'baisse'

ecart = (apres − avant) / avant
si Math.abs(ecart) < seuil (0.05) → 'stable'
return ecart > 0 ? 'hausse' : 'baisse'

La somme et non la moyenne : les deux moitiés ayant exactement sept jours, le rapport est le même et la somme se lit sans diviseur. Le seuil de 5 % se compare au rapport de l'écart à la période PRÉCÉDENTE, la référence dont on s'écarte. Les trois cas où une moitié vaut zéro sont tranchés AVANT le rapport, le dénominateur serait nul : zéro séance n'est pas une donnée manquante, passer de rien à quelque chose est une hausse.
