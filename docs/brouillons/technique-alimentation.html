Chargement de la sauvegarde des repas

Au chargement, la sauvegarde traverse une chaîne de conversions dans cet ordre : dropPreMigrationMeals à l'hydratation, puis dropSeedData, migrateTreatmentIds, purgeDeleted, mergeSideEffectNotes, mergeTableTennisSport, fillMealHunger, ensureStartingWeighIn.

moment  = 4 si type ∈ {lunch, dinner} ; 3 si breakfast ; 2 sinon
taille  = +1 si calories ≥ 700 ; −1 si calories ≤ 200 ; 0 sinon
écart   = (somme des codes de caractères de l'id) mod 2
avant   = borne0-5(moment + taille + écart)
chute   = 3 si calories ≥ 700 ; 1 si ≤ 200 ; 2 sinon
après   = borne0-5(min(avant − 1, avant − chute))   // chute ≥ 1, donc = borne0-5(avant − chute)

Une seule formule, sans branche : la quantité est canonique (g pour un solide, ml pour un liquide) et la fiche donne ses valeurs pour 100 de la même unité. La nature de l'aliment n'entre pas dans le calcul, elle ne sert qu'à l'étiquette.

apport(n) = fiche.n × facteur     pour n ∈ {calories, protein, carbs, fat, fiber}
