10. L'activité physique ↑ sommaire

Ce chapitre donne les entités du journal d'activité physique, les formules de calories et de score, les bornes de saisie et les fenêtres de calcul. Il dit comment chaque chiffre affiché par les écrans du chapitre fonctionnel → fonctionnelle est produit, dans quelles unités et dans quel ordre.

Entités

SportLog — une séance. Une ligne du tableau appData.sportLogs.

UserProfile, champs qui commandent ce domaine : sportTrackingEnabled: boolean, sportModuleHidden?: boolean, deleteAllButtonsEnabled?: boolean, targetWeight: number (kg, repli du poids). AppData : sportLogs?: SportLog[] et weightHistory: WeightLog[], lu pour le poids du jour.

Quatre valeurs vivent hors de la sauvegarde, dans le stockage local de l'appareil : glp1_active_sports (les activités cochées), glp1_sport_history_view (calendrier ou journal), glp1_period_sport_journal et glp1_period_sport_chart ({window, customRange}).

Rien de dérivé n'est stocké. Sont recalculés à chaque rendu : les calories d'une séance, les calories d'un jour, la durée d'un jour (étages convertis), les minutes pondérées, le score quotidien, les totaux et moyennes de la répartition, les points du graphe. Aucun champ calories n'existe sur une ligne.

Distance ou effort, jamais les deux

Le juge unique est parseDistanceInput(distance, sport). S'il rend une valeur, la distance « compte » :

hasDistanceField = !!onDistanceChange && isDistanceSport(sport)
distanceCounts   = parseDistanceInput(distance, sport) !== undefined
// distanceCounts → les trois crans d'effort sont disabled et à opacity-40

L'effacement passe par changeDistance : setDistance(value), puis if (!value.trim()) setIntensity('douce'). Le retour à « doux » n'a donc lieu que sur un champ vide ou blanc, pas sur une saisie devenue illisible.

Au journal, formatDistanceLabel(parseDistanceInput(brouillon, sport), sport) décide de la seconde ligne : non nul → la distance s'affiche à la place de l'intensité ; nul → l'intensité. Une ligne sans distance n'expose donc aucun champ distance : elle ne s'ajoute que par « Modifier ».

L'intensité reste écrite dans la ligne dans tous les cas : elle alimente encore la répartition par intensité du bloc de suivi et le partage.

Jugement des refus au clic Valider

refusSaisieSport est pure et prend {sport, showCustomDuration, customDuration, distance}. Elle choisit d'abord les deux règles, puis juge :

durationRule = sport === 'Montée escaliers' ? RULE_FLOORS : RULE_DURATION
distanceRule = getDistanceUnit(sport) === 'km' ? RULE_DISTANCE_KM : RULE_DISTANCE_M

if (showCustomDuration && !isAcceptable(customDuration, durationRule))
    refus.duration = boundsMessage(durationRule)
if (isDistanceSport(sport) && !isAcceptable(distance, distanceRule))
    refus.distance = boundsMessage(distanceRule)

Le tracker appelle cette fonction avant tout : si l'un des deux refus existe, il fait e.preventDefault(), mémorise les messages et sort — rien n'est enregistré, aucune félicitation n'est tirée. Sinon il vide les refus, tire la félicitation si ce n'est pas une correction, puis passe la main à form.handleSubmit.

Les messages s'affichent empilés juste avant le bouton, durée d'abord, distance ensuite. Effacement : retoucher la durée « Autre » efface duration, retoucher la distance efface distance, changer de sport ou de durée préréglée efface les deux, fermer ou rouvrir le formulaire aussi.

Une durée préréglée n'est jamais jugée : seule la branche « Autre » l'est. En aval, useSportForm.handleSubmit refuse encore en silence si parseInt de la durée retenue est NaN ou ≤ 0.

Unité et stockage de la distance

getDistanceUnit(sport) rend 'm' pour « Natation » et « Rameur / Aviron », 'km' partout ailleurs. La valeur enregistrée est toujours en mètres ; aucune étiquette d'unité n'est stockée.

parseDistanceInput(input, sport):
  si !isDistanceSport(sport)            → undefined
  trimmed = input.trim().replace(',', '.')
  si trimmed === ''                     → undefined
  value = parseFloat(trimmed)
  si !isFinite(value) || value <= 0     → undefined
  meters = unité === 'km' ? value * 1000 : value
  rounded = Math.round(meters)
  → rounded > 0 ? rounded : undefined

Les huit sports à distance, dans l'ordre du catalogue : Marche, Randonnée, Course à pied, Vélo, Natation, Rameur / Aviron, Ski de fond, Patinage / Roller. Ce sont exactement les clés de SPEED_CURVES.

Plafond quotidien (sport et temps pour soi)

L'ajout passe par addLogWithinDailyCap(sportLogs, log, 15, 'sport-'+Date.now(), onCapReached). Le décompte porte sur les lignes réellement présentes ce jour-là.

Encouragement après une activité

SPORT_ENCOURAGEMENTS compte huit phrases. Le tirage est pur :

candidates = SPORT_ENCOURAGEMENTS.filter(m => m !== previous)   // 7 si previous en fait partie
pool       = candidates.length > 0 ? candidates : SPORT_ENCOURAGEMENTS
index      = Math.min(pool.length - 1, Math.floor(draw * pool.length))
→ pool[Math.max(0, index)]

Il est appelé à la validation, et seulement si !form.editingLogId : une correction n'est jamais félicitée. Le tirage précède form.handleSubmit, qui allume le bandeau. La phrase est conservée dans l'état et repassée comme previous au tirage suivant.

Bornes « du … au … » d'un journal

Hors mode Choisir, le composant reçoit une plage fabriquée à la volée et l'écriture bascule la fenêtre :

                               : { startDate: getCutoffDateStr(window) ?? '', endDate: '' }
onChange = window === 'custom' ? period.setCustomRange : period.setCustomWindow

Modification et suppression d'une ligne

Trois gestes purs, communs à tous les journaux :

applyLogUpdate(logs, update) = logs.map(l => l.id === update.id ? snapLogTime({...l, ...update}) : l)
removeLogById(logs, id)      = logs.filter(l => l.id !== id)
handleClearSportHistory()    → sportLogs = []

La fusion conserve les champs absents de la charge ; l'heure est ramenée à la minute ronde inférieure. La suppression est franche : aucune marque, aucune corbeille. « Tout supprimer » remplace le tableau, après confirmation par ConfirmDeleteAllBlock avec l'étiquette « tout l'historique d'activité physique ».

Le formulaire complet (« Mettre à jour l'activité ») envoie tous les champs, distance comprise : effacer le champ écrit undefined et retire la distance. L'édition en place, elle, n'écrit rien si le brouillon est identique à la ligne, et refuse en silence une durée NaN ou ≤ 0, une date vide, un sport vide.
