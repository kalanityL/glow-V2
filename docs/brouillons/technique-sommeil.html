11. Le sommeil ↑ sommaire

Ce chapitre donne les formules, les seuils et les ordres de contrôle du domaine sommeil : la durée déduite de deux instants complets, la qualité pondérée, les refus à l'enregistrement, les points des graphes, la frise des nuits et les moyennes de l'accueil. Il décrit la version Mixte de la V1 ; la V2 ne porte pas ce domaine.

Entités

SleepLog est le seul objet stocké du domaine. Il vit dans AppData.sleepLogs?: SleepLog[], tableau facultatif — absent tant qu'aucune entrée n'a été écrite. La durée n'est jamais un champ : elle se recalcule à chaque lecture.

Dérivé, donc non stocké : la durée en minutes (sleepLogMinutes), la durée totale d'une journée, la qualité pondérée, le temps d'éveil, le rattachement d'une nuit à une soirée, les libellés « du … au … ». Deux drapeaux, une conjonction.

Conventions d'une entrée de sommeil

Une entrée porte deux instants complets. date + time = le réveil, et c'est ce couple qui date la ligne partout : tri du journal, case du calendrier, point de graphe, plafond quotidien, tendance. bedDate + bedTime = l'endormissement, champ à part entière, écrit et corrigible, jamais déduit de date. arbitrage non validé (décision de conception du 2026-08-18, notée « à confirmer par l'utilisatrice » dans src/types.ts).

Conséquence : une nuit commencée le 10 à 23:10 et finie le 11 à 06:45 appartient au 11. kind ne joue aucun rôle dans cette datation ; il ne sert qu'aux libellés, aux séries « nuit seule » et à la frise.

Durée d'un sommeil

Une seule fonction la calcule, sur des instants absolus construits champ par champ — jamais par new Date(chaîne), qui lirait le jour en UTC.

minutesOfDay(t)   : /^(\d{2}):(\d{2})$/ ; h > 23 ou m > 59 → null ; sinon h × 60 + m
instantMinutes(d, t) : /^(\d{4})-(\d{2})-(\d{2})$/ ; sinon null
                       → Date.UTC(aaaa, mm−1, jj) / 60000 + minutesOfDay(t)

sleepMinutesBetween(bedDate, bedTime, date, time) :
  bed  = instantMinutes(bedDate, bedTime)
  wake = instantMinutes(date, time)
  si bed = null ou wake = null → 0
  → wake > bed ? wake − bed : 0

sleepLogMinutes(log) = sleepMinutesBetween(log.bedDate, log.bedTime, log.date, log.time)

Unité : minutes entières. Aucun plafond ici : deux jours d'écart donnent 2 880 min. Le résultat est toujours ≥ 0.

Formats de durée du sommeil

Trois formateurs, jamais interchangeables. Tous bornent à 0 et arrondissent à la minute (Math.max(0, Math.round(minutes))).

formatSleepDuration(m)   // sleep.utils.ts
  h = ⌊total/60⌋ ; r = total mod 60
  h = 0        → « r min »          (« 40 min », « 0 min »)
  r = 0        → « h h »            (« 8 h »)
  sinon        → « h h rr »         (« 7 h 35 », minutes sur 2 chiffres)

formatSleepAverage(m)    // sleep.utils.ts
  → « ⌊total/60⌋ h rr »  sans espaces, heures TOUJOURS écrites
     465 → « 7h45 » ; 45 → « 0h45 » ; −10 → « 0h00 »

formatCalendarDuration(m) // shared/calendar.ts
  total < 60 → « total min » collé (« 45min »)
  sinon      → « ⌊total/60⌋ h rr » (« 7h35 », « 8h00 »)

Répartition constatée : formatSleepDuration dans le formulaire, la ligne du journal et l'infobulle du graphe ; formatSleepAverage dans les tuiles « Côte à côte », la moyenne du graphe, la frise des nuits et le message des 12 h ; formatCalendarDuration dans les tuiles du calendrier, la bulle, les tiroirs Journal et Tendances.

Une seule surface retouche le résultat : la ligne de tête de la bulle du calendrier applique formatCalendarDuration(duree).replace(/h00$/, 'h'), d'où « de 8h » au lieu de « de 8h00 ».

Refus d'une durée nulle

Deux gardes superposées. Le hook partagé refuse en silence, la page Mixte écrit le message.

// SleepTracker.handleSubmit — jugé AVANT tout le reste
si form.durationMinutes <= 0 :
    e.preventDefault()
    durationRefusal = "L'heure de réveil et l'heure d'endormissement sont
                       identiques : aucune durée de sommeil à enregistrer."
    return
durationRefusal = ''
form.handleSubmit(e)

// useSleepForm.handleSubmit — filet
si durationMinutes <= 0 : return       // rien n'est écrit, rien n'est dit

Le refus est effacé par changeBedTime, changeWakeTime, changeKind, openAddForm, openAddFormAt, startEdit et resetForm. Il n'est pas effacé par un changement de date : onDateChange reçoit form.setDate sans passer par un enrobage qui viderait durationRefusal. Le message reste donc à l'écran jusqu'au clic suivant.

En édition en place (journal et bulle du calendrier), la garde est si sleepMinutesBetween(...) <= 0 → return : la modification est abandonnée sans message et la ligne garde ses valeurs.

Interdiction des plages qui se recouvrent

sleepRangesOverlap(a, b) :
  aDebut = instantMinutes(a.bedDate, a.bedTime) ; aFin = instantMinutes(a.date, a.time)
  bDebut = instantMinutes(b.bedDate, b.bedTime) ; bFin = instantMinutes(b.date, b.time)
  si l'un des quatre est null            → false
  si aFin <= aDebut ou bFin <= bDebut    → false     // plage sans étendue
  → aDebut < bFin && bDebut < aFin                   // strict des deux côtés

findOverlappingSleep(logs, candidate, excludeId) =
  logs.filter(log => log.id ≠ excludeId && sleepRangesOverlap(log, candidate))

Les deux comparaisons étant strictes, le bout-à-bout passe : une plage qui commence exactement à la fin d'une autre n'est pas un recouvrement.

Formulaire. Le contrôle est sauté quand la plage est identique à l'originale :

plageInchangee = editingLogId présent
              && originalRange ≠ null
              && originalRange.bedDate = bedDate
              && originalRange.bedTime = bedTime
              && originalRange.date    = date
              && originalRange.time    = wakeTime
si !plageInchangee :
   conflits = findOverlappingSleep(sleepHistory ?? [], plage, editingLogId ?? undefined)
   si conflits.length > 0 :
      overlapRefusal = sleepOverlapRefusal(conflits[0], editingLogId ? 'modification' : 'ajout')
      return

Édition en place. Le contrôle ne court que si bedTime, date ou time ont bougé ; en cas de conflit, les trois champs du brouillon sont reposés sur les valeurs enregistrées avant d'afficher le message.

formatSleepRange(r) = `du ${JJ/MM de r.bedDate} ${r.bedTime} au ${JJ/MM de r.date} ${r.time}`
sleepOverlapRefusal(conflit, mode) =
  `Deux sommeils ne peuvent pas se recouvrir : cette plage recoupe le sommeil
   déjà enregistré ${formatSleepRange(conflit)}. ` +
  (mode = 'modification'
     ? 'La modification n'a pas été enregistrée : la ligne garde ses valeurs d'avant.'
     : 'Rien n'a été enregistré.')

Seul le premier conflit trouvé est cité, dans l'ordre du tableau sleepLogs — l'ordre d'insertion, pas l'ordre chronologique.

Arrondi des heures du sommeil

ROUNDED_MINUTES = [0, 10, 15, 20, 30, 40, 45, 50]

snapToRoundedMinutes(t) :
  si t ne vaut pas /^(\d{2}):(\d{2})$/ → t inchangé
  mm = Number(minutes) ; si mm > 59 → t inchangé
  arrondi = dernier m de ROUNDED_MINUTES tel que m <= mm   (sinon 0)
  → `HH:arrondi`                                    // l'heure ne change jamais

snapSleepTimes(log) = { ...log, time: snap(log.time), bedTime: snap(log.bedTime) }

Toujours vers le bas — l'application ne produit jamais une heure future. Appliqué dans handleAddSleep et dans handleUpdateSleep, donc à l'écriture et non à la saisie : la durée affichée par le formulaire est calculée sur les heures brutes, la durée relue après enregistrement sur les heures arrondies. Le sélecteur d'heure maison ne propose que ces huit minutes ; une valeur héritée d'une autre minute reste affichée telle quelle, en champ désactivé.

Frise des nuits : bornes et repères

bornesAxeNuits(lignes) :          // appelée sur [...nuits, ...moyennes] réunies
  bords = tous les coucherAxe et reveilAxe non nuls
  si aucun → { a: 480, b: 1320 }                  // 20 h → 10 h
  a = ⌊(min(bords) − 30) / 60⌋ × 60
  b = ⌈(max(bords) + 30) / 60⌉ × 60
  si b − a < 480 :                                // au moins huit heures
      centre = (a + b) / 2 ; a = centre − 240 ; b = centre + 240
  → { a, b }
reperesHeures({ a, b }, maxTraits = 7) :
  candidats = [120, 180, 240, 360, 480]
  pas = premier c tel que ⌊b/c⌋ − ⌈a/c⌉ + 1 <= 7      (sinon 480)
  pour m = ⌈a/pas⌉ × pas ; m <= b ; m += pas :
      heure   = ⌊versMinuit(m) / 60⌋
      libelle = « HHh »  (deux chiffres)
      minuit  = versMinuit(m) = 0

La demi-heure de marge est prise avant l'arrondi à l'heure, donc la barre ne touche jamais le bord. Les deux frises partagent l'axe : les bornes sont calculées sur la réunion des deux jeux de lignes, sinon les barres ne se compareraient pas. Une barre qui dépasserait l'axe est clippée au rail à l'affichage.

sleepDailyAverage(logs) :

  si journees = 0 → null
  → Σ sleepLogMinutes(log) / journees

sleepDailyAverageLast7Days(logs, now) :
  borne = getLocalDateStr(now − 6 × 86 400 000)
  retenus = logs filtrés sur log.date >= borne
  journees = dates distinctes de retenus ; si 0 → null
  → Σ sleepLogMinutes(retenus) / journees

Le dénominateur est le nombre de dates de réveil distinctes renseignées, pas le nombre de jours de la fenêtre ni le nombre d'entrées : une nuit et une sieste le même jour comptent pour une journée. sleepTrend(sleepLogs, days = 14, today) :
  si sleepLogs absent ou vide → []            // aucune série, la carte ne trace rien
  → trendDates(days, today).map(d =>
       sleepLogs.some(l => l.date = d) ? sleepMinutesOn(sleepLogs, d) : 0)

valeur de la carte = formatCalendarDuration(informedTrendMean(série)) + « /j »
