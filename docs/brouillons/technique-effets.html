Effacement du bandeau de confirmation

useDismissWhenHidden pose un ref sur le bandeau, remonte au premier ancêtre dont overflow-y vaut auto ou scroll, et n'efface que si trois conditions sont réunies au moment d'un événement scroll.

Heure arrondie vers le bas aux minutes rondes

L'ensemble des minutes admises est irrégulier : ROUNDED_MINUTES = [0, 10, 15, 20, 30, 40, 45, 50], croissant. L'arrondi est toujours vers le bas, pour ne jamais produire une heure future.

snapToRoundedMinutes(time) :
  m = /^(\d{2}):(\d{2})$/.exec(time)
  si !m                → time inchangé
  minutes = Number(m[2])
  si minutes > 59      → time inchangé
  r = dernière valeur de ROUNDED_MINUTES telle que valeur <= minutes, sinon 0
  → `${m[1]}:${pad2(r)}`

getRoundedLocalTimeStr(d) = snapToRoundedMinutes(`${pad2(d.getHours())}:${pad2(d.getMinutes())}`)

La règle s'applique deux fois : à la saisie, pour la valeur pré-remplie, et à l'écriture, où snapLogTime passe toute ligne portant un champ time de type string par snapToRoundedMinutes. Les trois gestes d'écriture du journal (ajout, écrasement au plafond, fusion de modification) y passent.

formatNumber(value, decimals = 0) :
  si !Number.isFinite(value) → ''
  negatif = value < 0
  arrondi = |Math.round(value * 10^decimals) / 10^decimals|
  [entiere, fraction] = arrondi.toFixed(decimals).split('.')
  groupee = entiere.replace(/\B(?=(\d{3})+(?!\d))/g, NBSP)   // NBSP = U+00A0
  utile   = fraction.replace(/0+$/, '')
