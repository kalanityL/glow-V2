20. Le partage ↑ sommaire

Ce chapitre décrit le seul partage du carnet : celui d'un badge gagné. Il donne la charge remise au système, la géométrie et l'encodage de l'image jointe, l'ordre des tests de capacité et le repli presse-papier.

Entités

Le partage n'écrit rien : aucune clé de stockage, aucun compteur, aucune trace du geste. Tous ses objets sont transitoires, construits à l'appel et perdus au retour. Il lit trois choses : la définition du badge, le palier atteint et le composant qui dessine le badge.

ObjetChampsNature
BadgeDefinition (lu) id (chaîne : athlete, lapin, kangourou, herisson), title, animalOrRole, categoryName, categoryEnabled(profile), getTier(appData), criteria (eveil, bronze, argent, or, notes?) Constante de code (ALL_BADGE_DEFINITIONS), non stockée. Le partage n'en lit que id, title et criteria.
BadgeTier (lu) 'aucun' | 'eveil' | 'bronze' | 'argent' | 'or', dans cet ordre croissant Palier calculé à la volée par getTier, jamais stocké par le partage.
BadgeDrawing (lu) Composant React de props { id, tier, sizePxOverride?, iconOnly? } Passé par l'écran qui partage, parce que chaque version du site a le sien.
File (produit) nom badge-{id}-{tier}.jpg, type MIME image/jpeg Dérivé, jamais écrit sur disque par l'application : remis au système, ou abandonné.
ShareData (produit) title, text, url, files? Charge remise à navigator.share. files n'existe que si le système l'accepte.

Partage d'un badge

Une seule fonction, shareBadgeItem(badge, tier, BadgeIcon, onNotice?). Elle compose le texte, tente de peindre la carte, puis remet la charge à la feuille de partage du système ; sans feuille de partage, elle copie le texte seul. Elle ne rend rien et ne lève rien.

texte  = `🏆 J'ai débloqué le badge "${badge.title}" Niveau ${BADGE_TIER_LABELS[tier].toUpperCase()} sur G(lp1)LOW`
carte  = await renderBadgeCardFile(badge, tier, BadgeIcon)   // toujours appelée, même sans navigator.share
fichiers = (carte && navigator.canShare && navigator.canShare({ files: [carte] })) ? [carte] : []

si navigator.share :
    charge = { title: `Badge ${badge.title} - GLP1LOW`, text: texte, url: window.location.href }
    si fichiers.length > 0 : charge.files = fichiers
    si navigator.canShare && !navigator.canShare(charge) && fichiers.length > 0 : delete charge.files
    essayer await navigator.share(charge)
    attraper err : si err.name !== 'AbortError' → console.error ; rien à l'écran
sinon :
    essayer await navigator.clipboard.writeText(texte)       // le TEXTE seul : ni titre, ni url
            onNotice?.('Lien et texte de partage copiés dans le presse-papier.')
    attraper → console.error ; rien à l'écran

Ordre des opérations : le texte d'abord, la carte ensuite (attendue), les deux tests de capacité enfin. Le premier test porte sur le fichier seul, le second sur la charge entière — titre, texte, adresse et fichier ; il ne peut retirer que les fichiers. Le libellé du palier vient de BADGE_TIER_LABELS, jamais de tier.toUpperCase(), pour que « ÉVEIL » garde son accent.

onNotice n'est fourni que par la page Badges (setShareNotice) ; le bloc de célébration appelle shareBadgeItem(badge, tier, BadgeIcon) sans quatrième argument et n'affiche donc jamais la notice. → fonctionnelle

La carte. renderBadgeCardFile peint dans un canvas de 600 × 600 unités mis à l'échelle 2 (ctx.scale(2, 2)) : le fichier sort à 1 200 × 1 200 px. Toutes les coordonnées ci-dessous sont dans l'espace 600 × 600.

Couleurs et nom du palier, écrits en dur dans le canvas (il ne lit ni le CSS ni le thème) : bronze #d97706 sur #fef3c7, « BRONZE » ; éveil #075985 sur #f0f9ff, « ÉVEIL » ; argent #2563eb sur #eff6ff, « ARGENT » ; or #ca8a04 sur #fef9c3, « OR ». Le bronze est la valeur par défaut : tout palier hors de cette liste, aucun compris, sort en bronze.

Le critère affiché est badge.criteria[tier === 'aucun' ? 'bronze' : tier], avec une exception unique : pour badge.id === 'athlete' (Kangourou Musclé), il est remplacé par « Récompense votre régularité dans la pratique d'une activité physique », quel que soit le palier.

Encodage : canvas.toBlob(resolve, 'image/jpeg', 0.95), puis new File([blob], `badge-${badge.id}-${tier}.jpg`, { type: 'image/jpeg' }). Pas de PNG, pas de transparence, pas de QR code.

Cas limites
  • Contexte 2D indisponible (getContext('2d') nul), roundRect absent, ou n'importe quelle exception du peintre : renderBadgeCardFile rend null ; le partage part en texte, titre et adresse, sans image.
  • toBlob rend null : même issue, null et partage sans image.
  • Le SVG du badge ne charge pas (img.onerror) : la promesse est résolue quand même, la carte est produite sans le dessin — fond, pastille, titre, critère, marque restent. Même chose pour le SVG de la marque : la carte sort sans logo.
  • navigator.canShare absent : le fichier est joint sans vérification et les deux tests sont sautés ; c'est la feuille de partage qui décide.
  • canShare refuse le fichier : la liste reste vide, la charge part sans files, la carte peinte est jetée.
  • canShare refuse la charge entière alors que la liste de fichiers est vide : rien n'est retiré, navigator.share est appelé quand même.
  • Annulation par la personne : AbortError, avalé, aucun message.
  • Autre erreur de navigator.share : console.error seulement, aucun message à l'écran.
  • navigator.share absent : la carte a déjà été peinte et est perdue ; seul le texte est copié. L'adresse n'est pas copiée, la notice l'annonce pourtant.
  • Copie refusée (permission, contexte non sécurisé) : console.error, ni notice ni message d'erreur.
  • Palier aucun : le texte dirait « Niveau AUCUN » et la carte porterait « ★ NIVEAU BRONZE ★ » avec le critère bronze. Le cas ne se produit pas depuis les écrans : la page Badges ne montre le bouton que pour les badges filtrés tier !== 'aucun', et le bloc de célébration ne s'ouvre que sur une montée de palier.
  • La notice de la page Badges n'a pas de minuterie : elle est effacée par setShareNotice(null) au clic sur le dessin d'un badge — le seul geste qui ouvre le badge en grand —, pas par la croix de fermeture.
  • Un titre de badge trop long n'est pas tronqué : fillText l'écrit sans largeur maximale et il peut déborder de la carte blanche. Seul le critère est contraint, à 420 unités, et le canvas le condense au lieu de le couper.

Camille dépasse 8 000 pas quatre jours sur les sept derniers : evaluateHerissonBadge rend argent et le bloc de célébration s'ouvre. Elle touche Partager. Texte : 🏆 J'ai débloqué le badge "Hérisson Marcheur" Niveau ARGENT sur G(lp1)LOW. Titre : Badge Hérisson Marcheur - GLP1LOW. Adresse : window.location.href. Fichier : badge-herisson-argent.jpg, JPEG 1 200 × 1 200 px de qualité 0,95, pastille ★ NIVEAU ARGENT ★ en #2563eb sur #eff6ff, titre « Hérisson Marcheur », critère « 8 000 pas par jour pendant 4 jours /7j ». Le bloc de célébration ne passant pas onNotice, un navigateur sans navigator.share copierait le texte et n'afficherait rien.

Le partage d'un badge appelle navigator.share et navigator.clipboard en direct, sans passer par shared/platform/share ni shared/platform/clipboard : le contrat de shareNative ne joint pas l'adresse au fichier et ne retire pas les fichiers refusés, donc l'aligner changerait ce que reçoit l'application de destination. Unification renvoyée à la conversion native. arbitrage non validé

Rien d'autre ne se partage. Deux surfaces existent dans le code sans qu'aucun écran du carnet mixte les affiche : ShareBlock (carte 1080 × 1920 peinte au canvas, shareNative, téléchargement PNG, lien Facebook, copie de légende pour Instagram), montée seulement par les écrans de la version cartes, et buildSportShareConfig (la légende d'une séance d'activité physique), qui n'alimente que ShareBlock. Les quinze maquettes de share/shareTemplates.tsx sont des aperçus dessinés en HTML : elles ne produisent ni fichier ni appel de partage.
